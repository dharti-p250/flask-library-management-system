# Flask Library Management System

A modern web-based Library Management System developed using Python Flask, MySQL, HTML, and CSS.

## Features

- User Registration and Login
- User Profile Management
- Browse Available Books
- Search Books by Title or Author
- Book Reservation System
- Available Book Tracking
- Admin Login
- Admin Dashboard
- Add and Delete Books
- User and Book Management
- Responsive and Modern UI

## Technologies Used

- Python
- Flask
- MySQL
- HTML5
- CSS3
- Jinja2
- Git & GitHub

## Project Purpose

This project demonstrates how Flask can be used to develop a complete web application with database connectivity, user authentication, book management, search functionality, and reservation features.
